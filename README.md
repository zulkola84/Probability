# Probability: fatigue reliability of a titanium femoral locking plate

Code and results for the manuscript *"Model-form uncertainty governs the fatigue reliability of a titanium femoral locking plate"* (submitted to the Journal of the Mechanical Behavior of Biomedical Materials).

The study is computational and uses published data only. It rebuilds the ASTM F382 four-point bending test of a grade 4 titanium plate reported by Bologna et al. (Front. Med. Eng., 2023, doi:10.3389/fmede.2023.1241312) as a calibrated linear-elastic finite element (FE) model, trains a Gaussian process surrogate on 416 FE runs, and propagates input uncertainty through the Goodman, Gerber and Smith-Watson-Topper (SWT) fatigue criteria with Monte Carlo simulation, FORM and Sobol sensitivity analysis. All input spreads are assumed; the plate width (16.365 mm) is calibrated to the published peak stress of 857.8 MPa. No new experiments were performed.

## Layout

| Folder | Content |
|---|---|
| `fe/` | Python scripts: geometry and mesh (Gmsh), CalculiX runs, Sobol design of experiments, surrogate, sensitivity, fatigue limit states, active learning, and the additional analyses (closed-form baseline, plasticity check, UTS and width cases, strength crossover) |
| `inputs/` | Published values (`bologna_inputs.md`) and digitised Fig. 6 curves of the source paper |
| `results/` | Outputs of every stage: FE samples (256 initial and 416 training runs), surrogate scores, Sobol indices, failure probabilities, reports (`stage3_report.md`, `stageA`...`stageF`) |
| `results/phase2/` | Outputs of the additional analyses (steps 3 to 8), with a `REPORT.md` per step |

Large raw solver output (nodal result files) is not included; it is regenerated by the scripts.

## Requirements

Python 3.10 or later, the packages in `requirements.txt`, and [CalculiX](http://www.calculix.de/) (`ccx` on the path) for the FE solves.

    pip install -r requirements.txt

## Main run order

    python fe/make_mesh.py          # quarter-model mesh (Gmsh)
    python fe/convergence.py        # mesh convergence
    python fe/run_samples.py        # Sobol design of experiments, FE solves
    python fe/sensitivity.py        # Gaussian process surrogate and Sobol indices
    python fe/fatigue.py            # limit states, Monte Carlo, FORM, runout load
    python fe/active_learning.py    # refinement near the failure boundary

Later scripts (`stage_*.py`, `width_cases.py`, `uts_cases.py`, `plasticity_check.py`, `closed_form_baseline.py`, `strength_crossover.py`, `goodman_gap*.py`) write to `results/`. Scripts that sample randomly use fixed seeds; failure probabilities from separate sample sets agree to the third decimal place.

## Key results (1200 N runout load, R = 0.1)

Probability of not reaching 10^6 cycles: 0.98 (Goodman), 0.34 (Gerber), 0.99 (SWT). Surrogate hold-out RMSE of peak stress: 2.9 MPa.
